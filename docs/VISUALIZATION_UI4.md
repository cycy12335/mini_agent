# UI-4：调用关系与定位证据

插件版本：0.4.0。兼容当前 Python 核心 0.3.0；本阶段不更改核心推理和工具实现，不需要 0.4.0 wheel。

已实现：

- 从完整审计事件中提取 find_callers/find_callees 查询，展示相关 SVG 调用图和调用点，支持聚焦上下游与键盘操作。
- 静态关系、候选/未解析调用、不完整范围与展示截断分别标记；不能当作运行时调用追踪。
- 展示问题条件、假设、检查、根因、证据和未确认项；修改前支持的结论明确显示需要复核。
- 代码跳转使用当前记录的引用白名单，校验路径边界、文本类型、敏感名称、链接、内容哈希和未保存编辑。过期引用拒绝跳转。
- 显示模型请求数、动作数、费用预留与剩余预算，金额来自核心记录，不是提供商账单。
- 只读导入单个运行编号文件夹，跨重开保存选择；导入记录不能执行恢复，新任务回到本地记录。
- prepare_visual_diagnosis.py 通过真实核心生成离线跨文件定位示例，无模型调用、无文件修复。

验证：16 项 Node 测试与语法检查通过，包含真实核心数据、宿主消息接线和模拟 DOM 渲染。真实 VS Code GUI、深浅主题、密集图布局尚待人工验收。
